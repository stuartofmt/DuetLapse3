# duetLapse3 - 3.7.x branch

Time-lapse videos of prints on Duet3D printers. This branch is the code for duetLapse3 6.x, for DWC / DSF 3.7.

The documentation - installation, settings, gcode commands and change notes - is on the main branch, in a folder for each version:

- [duetLapse3 6.2](https://github.com/stuartofmt/DuetLapse3/tree/main/docs/6.2)
- [duetLapse3 6.1](https://github.com/stuartofmt/DuetLapse3/tree/main/docs/6.1)
- [All versions](https://github.com/stuartofmt/DuetLapse3#versions)

Building the page: see [ui/README.md](ui/README.md).
