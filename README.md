## DuetLapse3

#### Based on an original DuetLapse created by Danal Estes https://github.com/DanalEstes/DuetLapse ####

## General Description

DuetLapse3 provides a highly configurable program for creating timelapse videos from printers using the Duet3D software.

It can be run as a one-of or continuously in the background.

It is also available as a plugin for Duet3D SBC

**In addition to a browser interface DuetLapse3 can be controlled directly from gcode.**

## Versions

There are currently two active versions, each maintained in its own branch:

- [3.6.x](https://github.com/stuartofmt/DuetLapse3/tree/3.6.x) - the current stable version.
- [3.7.x](https://github.com/stuartofmt/DuetLapse3/tree/3.7.x) - currently undergoing extensive modifications.

Installation guides, documentation and version history are in each branch.

Older versions are in the [Archived](https://github.com/stuartofmt/DuetLapse3/tree/Archived) branch.
